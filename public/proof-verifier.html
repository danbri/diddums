What this proves

For a composition proof, a successful replay establishes that the embedded JigScore program/event plan, LeanDSP Wasm modules and archived host-renderer sources reproduce the certificate’s exact stereo Float32 PCM hash; a pinned release reference can add a second expected-PCM identity. For a sine-speech proof, the verifier additionally rechecks the source clip and analysis trajectory. This does not prove that a trusted physical machine originally executed the render, nor does it prove the sound after DAC/speakers. Signing or remote attestation is a separate layer.
